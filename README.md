# Mihono

**A Mihono-based anime player and manga reader for Android — Manhwa reader.**

Organize large libraries, migrate entries, find online sources, customize the app around your workflow.

## About Mihono

Mihono is an independent Android anime and manga application built on top of [Nekoyomi](https://github.com/Seguaz/Nekoyomi) (Apache-2.0), which is based on [Aniyomi](https://github.com/aniyomiorg/aniyomi), itself based on [Mihon](https://github.com/mihonapp/mihon).

It keeps the reader, tracking and library tools of the Aniyomi ecosystem while adding features focused on **library management, migration, and interface customization**.

## Mihono Identity

Mihono is a maintained fork of Nekoyomi. New projects should base off `upstream` (the original Nekoyomi repository); `origin` is this Mihono repository.

## Highlights

### Custom series

- Fully customize per-series reading settings (text size, zoom, screen orientation, tap zones, etc.)
- Read with multiple reader types (vertical/webtoon and paged/continuous modes)

### Large library management

- Categories to help organize your large library with granular control

### Tracking

- Track your reading progress in a local, anonymized history.

### Full control over your viewing experience

- Many free, open source, and community-contributed extensions
